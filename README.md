# 24CS2016 - Building Application using Flutter - Lab Experiments
Register No: URK23CS7016

| Ex | Folder | Topic |
|----|--------|-------|
| 1 | `exp01_widgets_layouts` | Working with Widgets and Layouts |
| 2 | `exp02_responsive_catalog` | Adaptive and Responsive UI Design |
| 3 | `exp03_product_search` | Add Interactivity - Input and Forms |
| 4 | `exp04_car_mileage` | Form Validation using Stateful Widgets |
| 5 | `exp05_budget_calculator` | Application State Management (Provider) |
| 6 | `exp06_sqlite_students` | Data Persistence using SQLite |
| 7 | `exp07_firestore_employees` | Data Persistence using Cloud Firestore |
| 8 | `exp08_firestore_search` | Firestore Data Retrieval (Library Book Search) |
| 9 | `exp09_firestore_update` | Firestore Data Update (Update Book Copies) |
| 10 | `exp10_firestore_login` | User Login Authentication using Firestore |

Each folder contains `lib/main.dart` + `pubspec.yaml`. To run any one:
```
cd <folder>
flutter create .
flutter pub get
flutter run
```
Experiments 7-10 also need `flutterfire configure` (see the README inside each folder).
