# Exercise 6 - Data Persistence using SQLite
Course 24CS2016 - Building Application using Flutter | URK23CS7016

## Run
```
cd exp06_sqlite_students
flutter create .      # generates android/ios/web folders (keeps lib/main.dart & pubspec.yaml)
flutter pub get
flutter run
```

> sqflite does not run on Flutter Web. Run on an Android emulator/phone (or desktop with sqflite_common_ffi).
